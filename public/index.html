Приложение EVE SSO

Для доступа к ордерам, кошельку, скиллам, структурам и колониям нужно зарегистрировать локальное приложение. Это бесплатно и делается один раз.

  1. Откройте developers.eveonline.com/applications → Create New Application.
  2. Тип подключения — Authentication & API Access. Callback URL укажите ровно такой:
    http://127.0.0.1:8787/callback
  3. Scopes можно не выбирать при регистрации — они запрашиваются при входе.
  4. Скопируйте Client ID и вставьте ниже. Secret не нужен (используется PKCE).

Если вход зависает

Страница выбора персонажа — сторона CCP. Если она зависает: попробуйте режим инкогнито, отключите блокировщики рекламы, проверьте VPN/IPv6. Если браузер не может достучаться до локального адреса — вставьте сюда адрес из строки браузера после входа, приложение само обменяет код.

clientId, callback, доступность login.eveonline.com
