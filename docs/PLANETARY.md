# Планетарка (PI)

## Что показывает

- Колонии всех авторизованных персонажей.
- Добычу в час по экстракторам и ресурс планет.
- Таймеры экстракторов и статусы.
- Карту планеты с пинами (экстракторы, фабрики, командный центр, склад).
- Очередь «что перезапустить».

## Источник данных

- `GET /characters/{id}/planets/` — список колоний.
- `GET /characters/{id}/planets/{planet_id}/` — пины, циклы, продукты.
- Схемы производства — `/universe/schematics/{id}/` (кэшируются в `data/pi-cache.json`).
- Цены продуктов — из последнего скана, при отсутствии — Fuzzwork/ESI.
- Налог POCO — `esi-planets.read_customs_offices.v1` (если выдан scope).

## Статусы экстракторов

| Статус | Условие |
|---|---|
| `expired` | ресурс закончился |
| `critical` | осталось ≤ 6 часов |
| `soon` | осталось ≤ 24 часов |
| `ok` | больше суток |

Статус считается от `expiry_time` экстрактора. В нотификатор попадают `expired` и `critical`.

## Оценка добычи

```
qtyPerHour ≈ qtyPerCycle × 3600 / cycleTime
```

Показывается по каждому экстрактору и суммарно по колонии.

## Перезапуск

**Важно:** у ESI нет методов записи для планетарки. Приложение не может перезапустить
экстрактор за вас — это делается в клиенте EVE.

Что делает приложение:

- формирует очередь «что остановилось / скоро остановится»;
- отмечает выполненные пункты (чек-лист);
- показывает, сколько ресурса недособрано, если экстрактор простоял.

## Обновление

- `GET /api/pi/overview` — из кэша.
- `GET /api/pi/overview?refresh=1` или `POST /api/pi/refresh` — принудительно с ESI.
- Данные колоний кэшируются в памяти и `data/pi-cache.json`.

## Ограничения

- Богатство планеты (ресурсные точки) ESI не отдаёт — только текущие пины.
- Налог POCO известен только для структур, к которым есть доступ.
- Если персонаж не авторизован с нужными scopes, его колонии не появятся.
