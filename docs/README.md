## Принципы

- **Ноль внешних зависимостей.** Только стандартная библиотека Node.js 20+.
- **Только локально.** Сервер слушает `127.0.0.1` по умолчанию; токены не покидают машину.
- **Консервативные оценки.** Сканер не показывает «мечтательную» прибыль: цена выхода
  ограничена VWAP, объём — долей дневного оборота.
- **Честные ограничения.** Там, где ESI не даёт данных (чужие локации, приватные структуры),
  интерфейс показывает прочерк, а не выдуманное значение.

## Соглашения обозначений

- `ISK` — внутриигровая валюта, в интерфейсе сокращается как `k / M / B / T`.
- `нетто` — прибыль после налога и брокерской комиссии.
- `бид / аск` — лучшая цена покупки / продажи в стакане.
- `VWAP` — средневзвешенная цена по истории рынка.
