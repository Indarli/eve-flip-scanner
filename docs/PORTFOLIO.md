# Портфель

Вкладка «Портфель» показывает торговое состояние **выбранного персонажа**.

## Переключатель персонажей

В шапке вкладки — чипы всех авторизованных персонажей. Выбор запоминается
(`localStorage: eveflip.pf.char`). Если профиль нового персонажа ещё грузится,
показывается «Профиль загружается…» и страница сама обновляется через 5 секунд.

## Сводка

| Карточка | Что считает |
|---|---|
| Кошелёк | баланс персонажа |
| В ордерах | сумма `price × volume_remain` по активным ордерам, плюс эскроу |
| Склад | стоимость ассетов по лучшему биду |
| Реализовано | P&L по транзакциям (метод средней стоимости) |
| Подрезано | число ордеров, которые хуже рынка |

## Мои ордера

Источник — `/characters/{id}/orders/`. Для каждого ордера:

- тип, локация, buy/sell, цена, остаток;
- **лучшая цена** на этой станции (Fuzzwork aggregates: `station=<id>` для NPC-станций,
  `region=<id>` для структур);
- `Δ` — отклонение вашей цены от лучшей;
- статус:
  - `подрезан` — для sell есть аск ниже вашего, для buy — бид выше вашего;
  - `первый` — ваша цена лучшая;
  - `нет данных` — котировка недоступна.

### Алерт «подрезали»

Пока вкладка открыта, портфель обновляется раз в 30 секунд. Если появился новый
подрезанный ордер — карточка в браузере и звук. Дедупликация по `orderId`.

## P&L по типам

Считается по `/characters/{id}/wallet/transactions/` (до 10 страниц, ~2500 последних сделок).

Метод **средней стоимости**:

```
покупка:  qty += q; cost += q × price
продажа:  avg = cost / qty
          realized += q × price − min(q, qty) × avg
          qty -= min(q, qty); cost -= min(q, qty) × avg
```

Поля: куплено/продано, средние цены, реализованная прибыль, остаток.

**Ограничения:**

- если покупка была раньше загруженного окна транзакций, себестоимость может быть занижена;
- налоги и брокерские сборы в транзакциях не приходят отдельными полями, поэтому P&L —
  **до комиссий**; для точного нетто используйте ставки из профиля.

## Склад

Источник — `/characters/{id}/assets/` (до 20 страниц).

- Предметы агрегируются по типу и **корневой локации**.
- Если предмет лежит в контейнере или корабле, цепочка `location_id` разворачивается
  до станции/структуры (до 20 уровней).
- Стоимость — `qty × лучший бид` (регион The Forge как ориентир).
- Показываются топ-30 позиций по стоимости с колонкой **«Местонахождение»**:
  станция и система.
- Для приватных структур, к которым ESI не даёт доступ (`403`), выводится `структура #id`.

## Последние сделки

Таблица показывает **40 последних** покупок и продаж из `wallet/transactions`:
дата, тип, сторона (buy/sell), количество, цена, сумма и место.

- Позволяет сразу увидеть, исполнился ли buy-ордер и что именно куплено.
- Данные обновляются при полном обновлении профиля (автоматически, если профиль старше 15 минут).

## Кэш и обновление

- При открытии портфеля кошелёк и активные ордера **обновляются автоматически**, если им больше 2 минут.
- Полный профиль (сделки, склад) догружается в фоне, если он старше 15 минут.
- Результат кэшируется на 60 секунд отдельно по каждому персонажу.
- Кнопка «Обновить» сбрасывает кэш и пересобирает.
- Профиль персонажа обновляется фоново после входа и по кнопке «Обновить» на вкладке «Персонажи».

## Требуемые scopes

- `esi-wallet.read_character_wallet.v1`
- `esi-markets.read_character_orders.v1`
- `esi-assets.read_assets.v1`
- `esi-universe.read_structures.v1` (для приватных структур)
- `esi-location.read_location.v1` (для определения текущей станции)

Без них соответствующие блоки будут пустыми или частичными.
