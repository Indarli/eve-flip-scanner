# Безопасность

## Что хранится

| Файл | Чувствительность |
|---|---|
| `data/tokens.json` | **высокая**: access/refresh токены персонажей |
| `data/characters.json` | средняя: кошелёк, ордера, ассеты, транзакции |
| `data/config.json` | низкая/средняя: Client ID, структуры, настройки |
| `data/backups/*` | копии всего перечисленного |
| `data/cache/*` | публичные данные ESI |

Всё лежит локально и не отправляется никуда, кроме запросов к ESI, zKillboard и Fuzzwork.

## Сетевой доступ

- По умолчанию сервер слушает `127.0.0.1:8787` — доступен только с этой машины.
- Порт можно изменить: `PORT=9000 node server.mjs` или `config.server.port`.
- **В приложении нет аутентификации HTTP.** Если поставить `HOST=0.0.0.0`,
  любой в локальной сети получит доступ к токенам и данным. Не делайте этого
  без обратного прокси с авторизацией и TLS.

## EVE SSO

Приложение — **публичный клиент** (OAuth2 + PKCE), секрет не используется.
Запрашиваемые scopes:

| Scope | Зачем |
|---|---|
| `esi-skills.read_skills.v1` | навыки (Accounting, Broker Relations, Production) |
| `esi-wallet.read_character_wallet.v1` | кошелёк и транзакции |
| `esi-characters.read_standings.v1` | стендинги для брокерской комиссии |
| `esi-markets.read_character_orders.v1` | ордера |
| `esi-markets.structure_markets.v1` | стаканы структур |
| `esi-universe.read_structures.v1` | названия приватных структур |
| `esi-assets.read_assets.v1` | склад |
| `esi-location.read_location.v1` | текущая станция |
| `esi-location.read_online.v1` | онлайн своих персонажей (для интеля) |
| `esi-planets.manage_planets.v1` | колонии |
| `esi-planets.read_customs_offices.v1` | налог POCO |

- Токены обновляются автоматически. `refresh_token` даёт долгий доступ — берегите файл.
- Выход из аккаунта удаляет токены, но **сначала** сохраняет их в бэкап.
- Отзыв доступа: на <https://developers.eveonline.com> или через «Выйти».

## Что не делает приложение

- Не отправляет данные на сторонние серверы (кроме ESI/zKill/Fuzzwork).
- Не требует пароль EVE — только OAuth.
- Не имеет телеметрии.
- Не выполняет действий в игре (нет write-методов ESI), кроме чтения.

## Рекомендации

1. Не публикуйте `data/` в git и не пересылайте `tokens.json`/бэкапы.
2. Держите `HOST=127.0.0.1`, если не уверены в настройке сети.
3. Для удалённого доступа используйте VPN/SSH-туннель, а не открытый порт.
4. Периодически проверяйте список авторизованных приложений в EVE.
5. Храните бэкапы на защищённом носителе.

## Если токены утекли

1. Отзовите доступ приложения в EVE SSO.
2. Удалите `data/tokens.json` и `data/backups/tokens-*.json`.
3. Перезайдите персонажами в приложении.
4. Проверьте историю кошелька и ордера.
