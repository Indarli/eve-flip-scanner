# История версий

## 2.1.0 — 2026-11-17

### Сканер
- График истории в карточке товара: диапазоны **7 / 30 / 90 / 365 дней**.
- История запрашивается за весь доступный год (до 365 дней).
- В настройках появились **бюджет истории**, **доля рынка** и **окно интеля** — без правки JSON.

### Портфель
- Склад с местами: станция и система для каждой позиции.
- Разворачивание контейнеров и корабельных трюмов до реальной станции.
- Переключатель персонажей; новый персонаж появляется сразу, с состоянием «профиль загружается».
- Профиль больше не зависает на резолве структур (лимиты и таймауты).

### Интел
- Ускоренный расчёт прыжков: prefetch при сообщении, повтор после ошибки.
- Индикатор «…» вместо `?`, пока маршрут считается.
- Дифференциальный рендер: таблицы не перерисовываются, если данные не изменились.

### Инфраструктура
- Отрицательный кэш локаций (10 минут) — недоступные структуры не запрашиваются повторно.
- Подробная документация в `docs/` (архитектура, API, конфиг, данные, модули, эксплуатация, безопасность).
- Нотификатор в углу экрана: ники списком, `+N`, система, прыжки, корабль, направление.

## 2.0.0 — 2026-11-17

Первый публичный релиз. Проект разработан с ИИ-агентом **DeepSeek Harness** (модель `deepseek-flash`).

### Сканер рынка
- Пять NPC-хабов (Jita, Amarr, Dodixie, Rens, Hek) и структуры.
- Нетто-прибыль после комиссий (налог + брокер, стендинги, ставка структуры).
- Консервативная цена выхода `min(ask, max(VWAP30, bid))`, ограничение объёма.
- Скоринг по ISK/день, ROI/день, оборачиваемости, конкуренции.
- Детали: стакан, история 90 дней, порог безубыточности.
- Сравнение хабов, CSV-экспорт, пресеты фильтров, исключение SKIN/BP.
- Автоскан с браузерными уведомлениями и звуком.

### Портфель
- Переключатель персонажей.
- Мои ордера: лучшая цена, отклонение, статус «подрезан/первый».
- Алерт «подрезали» (карточка + звук).
- P&L по транзакциям (метод средней стоимости).
- Склад с местами: станция и система, разворачивание контейнеров.
- Оценка склада по лучшему биду.

### Планетарка
- Колонии нескольких персонажей.
- Экстракторы: добыча в час, таймеры, статусы `expired/critical/soon/ok`.
- Карта планеты, очередь перезапуска (чек-лист).

### Интел
- Разбор локальных чат-логов (UTF-16LE/BE), наблюдение за файлами.
- Резолв имён через ESI, корабли только из текста (category 6).
- Прыжки от онлайн-персонажей, направление «к вам/от вас».
- zKillboard: последние записи, таблица «ZKB рядом».
- `clr` очищает систему, `+N` показывается отдельно.
- Оповещения: карточка, звук, системные уведомления.
- Отдельный нотификатор в углу экрана (10 секунд).

### Инфраструктура
- SSE-обновления с откатом на опрос.
- Баннер недоступности ESI, авто-проверка, кнопка «Повторить».
- Мульти-персонажи через EVE SSO (PKCE), автообновление токенов.
- Автобэкапы `config`/`tokens`/`characters` (10 копий).
- Windows: запуск/остановка одним ярлыком, скрытый сервер, нотификатор.
- Docker, нулевые внешние зависимости.

### Документация
- `docs/`: архитектура, API, конфиг, данные, рынок, интель, планетарка, портфель,
  эксплуатация, безопасность.
